# Claviculário ECL — pacote para análise/migração

Este pacote contém somente código-fonte, dependências, scripts de instalação e assets necessários para análise técnica e migração do projeto.

## Não incluído
- dados de operação
- bancos/planilhas de dados
- backups
- protocolos gerados
- relatórios gerados
- logs
- arquivos `.env` ou credenciais

As pastas e extensões sensíveis/geradas estão protegidas pelo `.gitignore`.
